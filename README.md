# AMITOA — Corporate Website

株式会社AMITOA のコーポレートサイトです。

**Technology Beyond Limits. — 理想を、技術で現実に。**

- 単一ファイル構成：`index.html` だけで動作します（写真・翻訳もすべて埋め込み済み）
- 多言語対応：日本語（デフォルト）＋ 英語・中国語（簡体字）・ヒンディー語・スペイン語・アラビア語・フランス語・ベンガル語・ポルトガル語・ロシア語・インドネシア語
- `?lang=en` のように URL に付けると、その言語で開きます
- スマートフォン対応、アラビア語の右から左（RTL）表示に対応

## 公開方法（GitHub Pages）

Settings → Pages → Branch を `main` / `/ (root)` にして保存すると、
`https://<ユーザー名>.github.io/amitoa-website/` で公開されます。
